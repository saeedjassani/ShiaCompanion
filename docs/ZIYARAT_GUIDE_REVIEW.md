# Ziyarat Guide: review checklist

Everything in the Ziyarat Guide that waits on the owner or a native reader,
in one place. The guide itself is `docs/ZIYARAT_GUIDE.md` (read it first;
this file only lists the questions).

**How it works.** Tick a box (`- [x]`) when you have checked the item and
the text stands as it is, or write the decision next to it (for example
"use لِذٰلِكَ"). The next autopilot run applies each decision, then deletes
the item (the history stays in the commit). **Each autopilot run adds its
new owner items here, never only to its session notes in the guide.**
Items are grouped by entry or site; each says what to check, where (zikr
uid / tab / segment, guide key, or plan feature id) and the options.

Unless an item says otherwise, transliteration of every restored entry is
`translit.py` output read line by line, not native-checked, and the
instruction lines, tab labels and new merits are new English.
