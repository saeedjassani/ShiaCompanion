What this is and isn't

  • Screen sizes and type sizes are Apple's. Screen dimensions from the HIG's watchOS device table (halved from pixels); the Dynamic Type steps from the watchOS type scale, including the accessibility sizes. Large is the default.
  • It is a geometry model, not a screenshot. Text is measured with the browser's metrics — real SF Pro on a Mac or iPhone, a fallback face elsewhere. Row heights use Apple's published leading for each step.
  • The safe-area inset is not modelled. watchOS lays out edge to edge and the app supplies its own gutter, which is what the model uses. A system inset would make every horizontal verdict slightly worse.
  • Bordered button heights are estimated at the text leading plus 16pt of padding, which is the one number here with no published source.
